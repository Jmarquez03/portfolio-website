# portfolio-website

Source for [marquezengineering.com](https://marquezengineering.com), Jorge Marquez's engineering portfolio. It's being rebuilt from Hostinger Website Builder as a React site.

Planned stack: React + Vite + TypeScript, React Three Fiber (three.js) for 3D, Tailwind CSS. It builds to static files, deployed to Hostinger web hosting.

- `content/site-content.md`: inventory of all content from the old site
